## Main public delivery

### Official n8n module for Asaas

**npm package:** [`@asaasbr/n8n-nodes-asaas`](https://www.npmjs.com/package/@asaasbr/n8n-nodes-asaas)

Official integration to connect **n8n** to the **Asaas** API, enabling automations with resources such as customers, charges, notifications, PIX, and other platform flows.

```bash
npm install @asaasbr/n8n-nodes-asaas
```

This project complements my focus on **APIs and integrations**, connecting technical products to automations, SDKs, nodes, and low-code tools.

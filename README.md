## Principal entrega pública

### Módulo oficial n8n para Asaas

**Pacote npm:** [`@asaasbr/n8n-nodes-asaas`](https://www.npmjs.com/package/@asaasbr/n8n-nodes-asaas)

Integração oficial para conectar o **n8n** à API da **Asaas**, permitindo criar automações com recursos como clientes, cobranças, notificações, PIX e outros fluxos da plataforma.

```bash
npm install @asaasbr/n8n-nodes-asaas
```

Esse projeto complementa meu foco em **APIs e integrações**, conectando produtos técnicos a automações, SDKs, nodes e ferramentas low-code.
